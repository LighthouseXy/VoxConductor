# 显示屏与插座资料

当前屏幕：T154H7-C12-01 V2（商业标识 GMT154-01），240 × 240，ST7789 系列；31.42 × 33.67 × 2.17 mm，12P / 0.5 mm 排线。末端含补强厚度 0.30 ± 0.05 mm，屏幕下沿至末端 25.02 ± 0.5 mm（包含插入部分）。

[T154H7-C12-01-V2/](T154H7-C12-01-V2/) 保存用户提供的规格、结构图和正反图原件。规格书封面与页脚型号存在不一致，采购时按实物和商家确认型号核对；不据页脚引入另一块屏幕。

板座 J2：FH12-12S-0.5SVA(54)。[封装尺寸图](FH12-SVA-EDC3-159266-03.pdf) 与 [FH12 官方操作目录](Hirose-FH12-official-catalog.pdf) 第 18 页为立式接触方向依据：排线金属接触面背向棕色活动锁扣。

实物已做插座旋转返修，KiCad 仍保留原制板状态。不能把 CAD 中的原插座方向直接当作实物正确装配方向，也不能仅翻转排线；必须同时核对屏幕实际脚号与原理图。V3 说明中的实物排线布置仍需试装。

屏幕 VDD 工作上限 3.3 V；当前分压电源标称约 3.318 V，电压容差与实际背光电流仍属于需实测的电气边界。背光使用 Q1 与 R21（10Ω），不能从 GPIO 状态推断背光额定电流已满足。
