# 从电路到整机：我的硬件设计与装配

更新：2026-10-11。这里按设计和装配过程介绍硬件；信号连接、GPIO 与电气检查另见 [硬件与接线](HARDWARE_V1.md)。

我希望它既能完成显示与语音交互，也是一台可以独立摆在桌上的设备。因此，我把模块原型逐步整理为定制 PCB，再围绕屏幕、棱镜、按键和声音设计外壳。下面分别展示电路设计、PCB、加工实物、结构图与整机，不把设计图当作实测结果。

## 2. 电路：把显示、声音和交互放到同一块板上

| 模块 | 器件或接口 | 在设备中的职责 |
| --- | --- | --- |
| 主控与联网 | ESP32-S3-WROOM-1 | 运行固件、管理外设、连接 Wi-Fi 与云服务 |
| 显示 | ST7789 系列，240×240，FPC | 绘制时钟、天气、菜单与语音状态 |
| 采音 | INMP441，独立 I2S 输入 | 为语音识别、唤醒与声学诊断采集声音 |
| 播放 | MAX98357A、外接扬声器 | I2S 音频输出、语音播报与本地媒体 |
| 姿态 | MPU6050，I²C | 倾斜翻页、滚动与时间调节 |
| 存储 | microSD，独立 SPI | 媒体、文字记录、任务与快照 |
| 手动交互 | 外接实体按键 | 确认、返回、按住说话和取消会话 |
| 供电与维护 | USB、电源转换、复位/下载电路 | 供电、烧录、调试与外围电源管理 |

![主原理图，从 KiCad 工程直接导出](images/2026-10-11/schematic-main.svg)

[打开可放大的主原理图 SVG](images/2026-10-11/schematic-main.svg) · [完整原理图 PDF](../hardware/exports/VoxConductor-schematic.pdf) · [KiCad 工程](../hardware/VoxConductor.kicad_pro)。器件值和网络名称保留工程原样，核对接线请放大查看。

我将显示、SD、采音和播放安排到各自对应的接口上。这样软件可以分别管理它们的速率、队列和错误恢复；并不意味着外设之间不存在 CPU、内存或总线竞争。Flash/PSRAM 容量需要依据模组完整后缀和启动日志确认，不能只看到 WROOM-1 就推断容量。

## 4. 装配部件：每一部分负责什么

![装配部件全景，保留部件之间的位置关系](images/2026-10-11/assembly-parts-overview.jpg)

另一张 [不同角度的部件全景](images/2026-10-11/assembly-parts-angle.jpg) 补充屏幕、外壳和透明件的形状。图中黄色纸包裹的是方形分光棱镜；我补充了去掉包装的独立实拍，下面按电子、显示光学、结构与交互部件介绍。

| 部件 | 用途与装配关注点 |
| --- | --- |
| 主板 | 承载主控与外围电路，按底盖柱位固定，避免排线和线束压住接口 |
| 显示组件 | 屏幕与 FPC 提供图像；接触面和针序按实物接口确认，排线不能夹在接缝中 |
| 主壳与底盖 | 定位电路板、按键和光学组件，保留 USB、SD 与声音通道 |
| 显示固定框 | 固定屏幕/光学组件，检查螺钉、边缘压力和观察方向 |
| 方形分光棱镜 | 将屏幕光线通过分光界面反射至观察方向，形成悬浮显示观感；保护光学面，避免磕碰与污染 |
| 透明支架 | 承托光学组件并保持与屏幕的相对位置；装配时避免划伤或过紧夹持 |
| 实体按键 | 在不依赖语音时完成确认、返回、录音与取消，注意活动空间和走线 |
| 扬声器 | 播报语音与媒体，固定后检查出声通道、线束和结构振动 |

八张局部图从部件全景裁出，棱镜图使用 10 月 11 日新增实拍，均未重绘器件。棱镜的分光比例、材料和镀膜规格没有可靠采购记录，不从照片推断。全景与局部图不代替采购清单；[原始部件照片](images/2026-10-10/assembly-parts-overview.jpg) 保留高分辨率版本。

显示链路是“SPI 屏幕图像 → 分光棱镜的内部界面 → 观察者”，不是体积全息显示。黑底减弱背景杂光，亮色字符提供反差；镜像/旋转补偿决定观察方向上的字形。光学件的定位、环境照明和观察角度共同影响清晰度，不能仅提高屏幕亮度解决。结构还要兼顾按键触达、接口插拔、麦克风收音与扬声器固定。
