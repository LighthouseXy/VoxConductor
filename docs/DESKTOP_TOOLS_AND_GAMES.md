# 桌面交互、天气与日常工具

更新日期：2026-10-10。文件名保留以兼容旧链接；游戏已经备份并从当前固件移除，本页不再作为游戏说明。

我以实体按键和姿态传感器组织界面，目标是让基础操作可预测：单击进入或确认，双击返回，倾斜用于选择或连续调节。语音忙时的按键优先用于取消，不同时触发页面操作。

## 主页与锁屏

主页有圆形时钟、壁纸加数字时间两种组合；壁纸选择与主页类型分别保存，恢复圆形时钟不要求删除壁纸。锁屏统一显示无壁纸的圆形时钟，不继承主页背景。

主页二级页面只保留闹钟设置，待办和备忘录留在任务入口。调整闹钟时先选小时或分钟，倾斜越大变化越快，回到中位停止，单击确认、双击返回。

## 天气

- 主页面显示当前天气与温度；数据来自网络，不是室内传感器。
- 未来 12 小时页用滚动列表呈现，支持姿态变速滚动；一屏未显示全部时刻不代表只获取了几小时。
- 两个天气二级页允许向同一方向循环切换，不要求每次反向返回。
- 参数页展示 USAQI/PM2.5、当前 UV、当日 UV 大于 3 的时段、风与湿度，移除底部重复说明以扩大卡片空间。
- 失败时区分无数据、旧缓存与更新时间，不把缺失值写成 0。

## 任务、专注与媒体

闹钟、提醒、待办和备忘录使用有限本地任务记录。钟点提醒需要有效时间；“工作日”按周一至周五处理，不包含法定节假日表。专注/倒计时使用单调时钟，恢复时不会把断电时间直接当成完成的专注时长。

音乐、环境音和静态/动态壁纸放在 SD。语音与媒体共用音频输出，需要协调播放，不承诺所有声音同时混播。资源包与其署名另行发布，不随本次文档和演示视频提交。

## 设置与网页

设置包含音量、亮度、方向、校准、专注/休息、唤醒、存储和外观等。保存失败必须区分“暂时生效”和“已持久保存”。唤醒开关开启与模型是否就绪是两种状态。

同网管理网页可以调整部分设置、管理媒体和执行诊断，不需要配对码；仍需在设备上打开管理窗口。它不是首次 Wi-Fi 配网，也不是公网管理服务。

## 回归重点

1. 单击、双击、长按在同一页面含义一致；语音中按键取消不误触桌面。
2. 切换主页后立即可见，重启后仍保持；锁屏不出现壁纸。
3. 闹钟慢倾斜精调、快倾斜快速调整；确认后按实际时间触发。
4. 天气二级页循环切换、12 小时列表两端滚动、AQI/UV 长文字不重叠。
5. 网页与语音改设置后，在设备端回读；SD 或 NVS 失败不能报保存成功。
