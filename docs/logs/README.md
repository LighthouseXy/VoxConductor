## 记录规则

- “已完成”只记录已有代码、构建产物、串口输出、生成文件或实机现象支持的结果。
- API Key、Wi-Fi 密码及其他真实凭据不得写入日志。
- 代码已接入但未实测，明确标注“源码完成 / 待验收”；计划未实施则放入“遗留事项”。主机检查、构建、烧录、实机听测分别记录。
- 后续每天新增 `YYYY-MM-DD.md`，并同步更新本索引。
- 缺少当日原始证据时不补写推测性日记；阶段总结统一记在实际整理日期。
