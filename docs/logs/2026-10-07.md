# 2026-10-07｜免唤醒语音打断与阶段文档整理

## 今日目标

把连续对话扩展为回答中可直接打断，并整理这一阶段按日开发记录、发布材料与网页改进方案。

## 已完成

- 最新源码默认启用回答生成/播放期间的本地 AEC/VAD 打断；空闲 Computer 唤醒与回答中打断仍是独立路径。
- 扬声器保持 24 kHz 播放，仅回声参考转换到 16 kHz；默认参考延迟 40 ms、讲话确认 200 ms、起始稳定期 160 ms。
- 保留约 400 ms 新讲话开头，旧轮清理期间继续有界采集；旧轮退出后串行进入新请求，不叠加两个云端对话流水线。
- 按键取消优先于声学接话；旧 DMA 音频停止，取消/失败轮次不记成完整播报，不自动恢复旧问题。
- 接话缓冲放 PSRAM、按需准备，分配失败保留按键路径，不让可选声学能力使整机启动失败。
- 按日期补记 9 月 25 日至本日的十一篇日志，保留原有八月日志；更新当前功能说明、GitHub 同步清单、演示材料要求和管理网页设计。

## 检查与边界

此前本日声学改动有 24 项非编译检查及格式检查通过记录；未运行 C 构建、未烧录、未校准整机声学，不能称为已验证稳定全双工。当前文档整理也不执行构建、烧录、付费 API 调用或 GitHub 推送。

最新声学验收需要：扬声器单独播放不误打断、真实讲话能触发、开头不丢、旧声音不串入、按键取消不自动接话，以及长时间内存稳定。见 [语音实施方案](../VOICE_DIALOGUE_AND_MEMORY_PLAN.md)。
