# 2026-08-09 开发日志

## 当日目标

完成 INMP441 采样验证与故障定位。

## 已完成

- 配置 ESP32-S3 I2S 接收通道：16 kHz、32 位槽、立体声帧。
- 首块麦克风持续返回全零；使用万用表验证 VDD-GND 为约 3.29 V。
- 发现首块模块 `SD` 到 `GND` 两个方向持续蜂鸣，阻值约 0.02 Ω，判定模块或焊接存在短路故障。
- 更换新的 INMP441 模块后获得非零采样。
- 通过切换 L/R 验证左右声道选择正确。
- 从原始幅值统计改为去除直流分量后的 `AC avg/peak`，安静和发声时出现明显差异。
- 在 LVGL INFO 页面加入麦克风音量条和百分比显示。
- 根据实测数据调整噪声底和满量程映射，解决轻微声音立即显示 100% 的问题。

## 关键认识

- 原始样本最大值不等于稳定音量，必须去除直流偏置并在一段采样窗口内统计。
- I2S 引脚配置正确不等于模块本身正常；供电、短路和实际数据都需要分别验证。

## 遗留事项

- 正式语音流程中需要避免音量检测任务与录音任务同时读取同一个 I2S 通道。
