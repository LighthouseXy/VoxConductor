# MPU6050 / MPU6500 姿态导航

更新日期：2026-10-10。基础页、九宫格、天气/闹钟连续滚动共用安装方向；游戏已移除。当前已恢复左倾向左、右倾向右、上倾向上、下倾向下；详见 [桌面操作](DESKTOP_TOOLS_AND_GAMES.md)。本页描述开发版，本批不发布新固件。

驱动按 `WHO_AM_I` 识别 MPU6050（`0x68`）和 MPU6500（`0x70`），不以模块丝印判断型号。MPU6500 单独设置 `ACCEL_CONFIG2(0x1D)=0x03`，启用41Hz加速度低通滤波；两者使用±2g量程，采样分频配置为50Hz。启动时读回加速度配置，失败则不启动手势任务。MPU6500适配仍需实机完成下述翻页验证。

启动仅探测0x68/0x69两个地址；无应答时最多尝试3轮，轮间隔100ms，成功立即进入型号检查和初始化。超时等总线错误直接报告并停止初始化。已移除临时的10秒等待、全地址扫描和GPIO配置转储；保留连接、校准、就绪与错误日志。身份及配置读回细节使用DEBUG日志。

2026-09-27按用户要求关闭整条周期诊断日志（`APP_MOTION_DIAGNOSTICS=0`），不再周期输出偏移、采样间隔和识别状态。保留连接、校准及错误，默认不输出 XYZ、偏移和识别过程；实际页面事件以当前界面日志为准。需要排查时可将开关改为1，每500ms输出一次。固件使用定制PCB引脚。

## 功能与动作定义

向左轻摆切上一页，向右轻摆切下一页，四个基础页首尾循环。单击进入/确认、双击返回，按键不再切下一页；录音、生成、播放期间不接受基础翻页。二级菜单使用四向选择，天气十二小时与闹钟时间使用按倾斜幅度变速的连续输入。

当前使用MPU6050/MPU6500加速度计识别左右倾斜式轻摆：模块沿设备左右方向的轴，其滤波后加速度相对校准中位改变达到0.22g时进入动作确认。它不是位移追踪，不能保证识别保持姿态不变的纯水平平移，也不需要大幅快速甩动。此版本不使用DMP或姿态融合框架。

## 接线

以下为定制PCB网络，不再使用旧原型的GPIO10/11（新板已用于屏幕）。GPIO编号不是模组封装脚号。

| MPU信号 | 新PCB连接 |
| --- | --- |
| VCC | 3V3 |
| GND | GND |
| SDA | GPIO39 |
| SCL | GPIO40 |
| AD0 | GND，选择地址0x68 |
| INT | GPIO41，当前驱动轮询，不配置中断 |

代码兼容0x68/0x69两个地址；新板AD0接地，预期地址0x68。I²C保持100kHz，使用板载R9/R10上拉到3.3V。驱动仍按WHO_AM_I区分MPU6050/MPU6500。

## 安装与校准

2026-09-27装壳测试确认左倾Y为正、右倾Y为负，使用Y轴（`APP_MOTION_AXIS=1`）和方向-1，将左倾映射为上一页、右倾映射为下一页。改变安装方式后仍需实测核对，不由I²C引脚迁移推断轴向。

手势识别不再等待校准：启动默认使用0mg中位，适用于当前水平安装的X/Y轴。开机若已倾斜，保持该姿态不直接翻页；经过中间后即可识别左右倾斜，不要求先静置一秒。第一帧滤波值直接取实测值，避免初始零值伪造一次回中。后台校准只是中位微调，不是功能启用条件。串口会出现以下信息（型号及中位数值随实机变化，连接日志顺序可能因任务调度而不同）：

```text
MPU6050连接成功：地址=0x68，SDA=39，SCL=40
MPU6050手势已启用：轴=1，默认中位=0mg；经过中间即可左右倾斜翻页，放平静置可后台校准
后台中位校准：轴=1，中位=0 -> 25mg
```

后台校准要求X/Y均在±180mg内、Z正向至少850mg、总加速度有效且未进行语音对话，连续稳定约1秒。三轴相对候选起点波动不超过60mg；移动、姿态不符、数据异常、语音占用或超过100ms的采样间断都会重新累计，但不会因校准未完成而跳过动作识别。校准后只更新至少20mg的中位变化，避免噪声反复重置手势。周期日志显示“中位来源=默认/校准”，两种状态均可识别动作。

配置位置：`firmware/main/app_motion.h`。

- 安装改变导致方向相反时，在 app_motion.h 核对 APP_MOTION_DIRECTION 和 APP_MOTION_VERTICAL_DIRECTION（当前均为 -1），所有页面共用屏幕坐标；不要分别反转各个消费者，也不要交换 SDA/SCL。
- 改变安装方式后，按实际左右倾斜数据选择 `APP_MOTION_AXIS`（0=X、1=Y）；当前为1。本版默认中位和后台校准针对X/Y检测轴、Z正向朝上的安装方式，配置成Z检测轴会在编译时报错。它不自动适配任意竖装或倒装。
- 灵敏度：`app_motion_gesture.h` 中 `MOTION_TRIGGER_MG` 默认220；更小更灵敏，也更易误触。先确认轴向再调阈值。

触发要求偏移达到±220mg并持续40ms。正常翻页后至少冷却400ms；只需经过中位±160mg范围，或在连续有效采样中跨越该范围，即可记录“已过中位”，无需在中间停住120ms。冷却期间的过中位记录会保留，冷却结束后再判断下一次动作。保持同一侧倾斜不连翻；回到中间本身不翻页，但继续摆到另一侧并满足阈值会翻向另一页。

正常启动和后台校准更新后经过中间即可准备动作。实测静置约1.2g，旧0.75～1.25g有效范围会在轻微过渡波动时拒绝采样；现在使用0.65～1.50g的动作可信范围，这不是对传感器精度的校准。短于100ms的超限采样只跳过，并重新累计40ms动作确认，不清除已有待触发状态；无效帧不能制造过中位。持续异常达到100ms、读取失败、超过100ms的采样间断或语音占用后仍需稳定回中120ms。无效数据绝不触发翻页。上述时间不含采样、滤波和界面调度延迟；实机误触率仍需确认。

后台校准只接受放平数据，不会将534mg或686mg这样的倾斜值保存为中位。中位更新时同步重置滤波与手势状态，避免旧偏移残留。本版已通过软件回归测试，尚待实机验证。

## 验证

在VS Code选择固件工程 `firmware`，编译并烧录：

1. 开机时先倾斜保持，确认不会自动翻页；短暂经过中间（不静置一秒）再左右倾斜，即使“中位来源=默认”也应能触发。
2. 右倾轻摆一次，确认切下一页；保持倾斜时不连续跳页。
3. 从右侧经过中间直接左倾，不刻意在中间停顿，确认反向翻页；两次动作仍受400ms冷却限制。
4. 连续操作测试首尾循环；桌面轻微振动不应翻页。
5. 长按录音和播放回答时摇动，不应切页。对话结束后先回中，再摇动。
6. 断电后拔下模块再启动，其他功能仍能使用，仅提示“摇动翻页未启用”。不要带电反复插拔测试。
7. 放平稳定约1秒应出现“后台中位校准”，之后左右倾斜仍可翻页；保持倾斜不能更新中位。

不以是否出现逐次偏移/识别日志判断传感器有效；该日志默认关闭。需要诊断时开启 APP_MOTION_DIAGNOSTICS，约每 500 ms 输出，不改变约 20 ms 采样。器件ID不是0x68或0x70时拒绝启用；连续5次读取失败会停用本功能，检查接线后重启。

`sh tests/run_cloud_checks.sh` 直接调用固件共用的采样处理入口，覆盖未校准启动、快速过中位、左右识别、短脉冲、持续倾斜、冷却、语音禁用、数据异常、计时回绕及后台校准。代表性实测读数用于构造测试，不等同于完整实机采样回放。新增逻辑已通过软件测试，尚未完成本版实机验证；软件测试不能验证实际安装方向、灵敏度或误触率。
