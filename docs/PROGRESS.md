## 已实现的代码

- ESP32-S3 / FreeRTOS / LVGL；按键或WakeNet→实时ASR→本地精确命令或有限模型工具循环→设备ACK→释放模型连接→TTS/I2S。生产链路由设备直连云服务；旧server目录与流式音频桥保留为历史/实验内容。
- 在语音成功轮次边界串行服务提醒和网页作业；共享180秒软件deadline传递到网络/模型/设备操作，不把存储和驱动清理称作硬实时保证。
- 会话提交显式区分成功、可重试失败、永久失败和结果不确定。设备有写前意图、已确认/未知持久回执；未知动作不自动重放，容量满则拒绝新动作。
- 模型提醒与备忘录先形成候选，下一轮精确“确认执行”才保存。重复确认不重复写入，取消和重载不恢复易失执行授权。
- “查看任务保存状态”实际读取校验快照；“重试任务保存”先对账，已有ID恢复运行态任务但不重写，不存在时重新展示候选并等待确认。比较成功后才恢复generation、解除不确定写入栅栏。
- 取消检查覆盖本地命令准入与最终模型回答；本机候选取消同时清理任务重试授权；工具回执按call ID回传。保留记忆来源、TTL、版本、旧值与删除屏障。

## 构建与复现前提

ESP-IDF 6.0.2 / ESP32-S3，本机既有组件锁定版本见firmware/dependencies.lock。

1. 依据firmware/main下*.example.h创建本地凭据头；填写自己的配置，禁止提交。
2. 提供有使用权的24 kHz、16-bit little-endian、单声道PCM到firmware/main/reminder.pcm；它是当前CMake嵌入资源，干净克隆缺少此文件时不能直接完成固件链接。本次未提供该资源或对来源不明音频授予权利。
3. 在firmware目录使用ESP-IDF的idf.py build；依赖下载需要自己的网络环境。本次没有新增云端账号、权限、付费调用或发布固件。
4. 主机测试入口：python3 tests/agent_safety/run_checks.py；python3 tests/agent_safety/run_task_reconcile.py。需要C编译器、Python3与托管cJSON组件源码。
