## 后续代码同步要准备什么

1. 固定固件版本和 ESP-IDF/组件锁文件，核对实际板卡、Flash、PSRAM、模型与分区。
2. 以 CMake 引用为准整理源码和辅助头文件，不把已移除游戏、旧播放路径当成当前依赖。
3. 同步配置示例、字体/提醒等必要资源、主机测试与工具，明确哪些测试需要额外媒体包。
4. 用占位符替换示例凭据；检查固件二进制是否包含个人密钥，不直接公开私人烧录文件。
5. 在干净克隆上检查依赖完整性，再构建、烧录和实测；三者与源码检查分别记录。
6. 完整媒体包另行发布，保留作者、许可、来源、格式和校验值，不同时提交 ZIP 与展开副本。

没有实际发布 Release 时不写下载地址，也不将历史资源包大小当作新版本统计。

## 公开表述

我会使用第一人称讲清楚自己做了什么，同时保留事实边界：棱镜是二维屏幕反射；ASR/LLM/TTS 需要云服务；空气质量为网络模型数据与 US AQI；“已接入”“已有成功演示”“重复验收通过”分别表述。

目前不会写“稳定全双工”“零延迟”“所有功能均已验证”或“最新固件已完整发布”。项目文档独立维护，小红书稿暂停，不由 GitHub 推送代替社交平台发布。
