# VoxConductor V1 硬件与接线

最后更新：2026-08-26

本文记录当前实装原型使用的硬件、GPIO 和电气约束。当前器件状态见 [`BOM.csv`](./BOM.csv)；未实际完成的产品化器件在 BOM 中明确标记为 `not_implemented`。

## 1. 当前原型

| 子系统 | 当前器件 | 当前用途 |
| --- | --- | --- |
| 主控 | ESP32-S3 N16R8 Nano | 固件、Wi-Fi、UI、音频、存储控制 |
| 显示 | ST7789，1.3 英寸，240×240，SPI | LVGL 信息页和语音状态 |
| 光学 | 25.4 mm 分光棱镜 | 反射显示；固件补偿显示方向 |
| 音频输入 | INMP441 I2S 数字麦克风 | 16 kHz 语音采集 |
| 音频输出 | MAX98357A + 4 Ω / 3 W 扬声器 | 24 kHz PCM 播放 |
| 存储 | microSD SPI 模块 + microSD 卡 | 追加保存文本会话 |
| 交互 | 四脚瞬时按键 | 短按切页、长按录音、松开发送 |

当前原型采用开发板、模块和面包板/跳线搭建；没有定制 PCB、电池和成品外壳。

## 2. GPIO 分配

### ST7789 显示屏

| ST7789 | ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC | 3V3 | 当前模块按 3.3 V 使用 |
| GND | GND | 共地 |
| DC | GPIO4 | 数据/命令选择 |
| RES | GPIO5 | 硬件复位 |
| SDA | GPIO6 | SPI MOSI |
| SCL | GPIO7 | SPI SCLK |
| BLK | 3V3 | 当前常亮，不支持软件调光 |

显示使用 `SPI2_HOST`、40 MHz、SPI mode 3，不使用 MISO 和 CS。ST7789 设为 240×240、Y 偏移 80；`mirror_y=true` 用于补偿当前棱镜结构的上下翻转。

### INMP441 麦克风

| INMP441 | ESP32-S3 | 说明 |
| --- | --- | --- |
| VDD | 3V3 | 仅使用 3.3 V |
| GND | GND | 共地 |
| SCK | GPIO8 | I2S BCLK |
| WS | GPIO9 | I2S LRCLK |
| SD | GPIO14 | I2S 数据输入 |
| L/R | GND | 选择左声道 |

固件以 32 位 I2S 槽接收数据，提取左声道后转换为 16 位 PCM。录音采样率为 16 kHz。

### MAX98357A 功放

| MAX98357A | ESP32-S3 / 电源 | 说明 |
| --- | --- | --- |
| Vin | 5V | 功放电源 |
| GND | GND | 与主控共地 |
| BCLK | GPIO15 | I2S 位时钟 |
| LRC | GPIO16 | I2S 左右时钟 |
| DIN | GPIO17 | I2S 音频输出 |
| SD | 模块默认状态 | 当前未由 GPIO 控制静音 |
| GAIN | 模块默认状态 | 当前主要通过软件缩放音量 |
| SPK+ / `+` | 扬声器一端 | BTL 差分输出 |
| SPK- / `-` | 扬声器另一端 | BTL 差分输出 |

固件输出 24 kHz、16 位 Philips I2S，把单声道样本复制到左右槽。当前软件音量为 35%。

### microSD 模块

| microSD 模块 | ESP32-S3 | 说明 |
| --- | --- | --- |
| VCC | 3V3 | 当前模块已在 3.3 V 下验证 |
| GND | GND | 共地 |
| CS | GPIO2 | SPI 片选 |
| SCK | GPIO13 | SPI 时钟 |
| MOSI | GPIO18 | 主控到卡 |
| MISO | GPIO21 | 卡到主控 |

microSD 使用 `SPI3_HOST`，最高 10 MHz，挂载点为 `/sdcard`。固件不会在挂载失败时格式化卡；建议使用 FAT32。

### 实体按键

| 按键端 | ESP32-S3 | 说明 |
| --- | --- | --- |
| 一侧 | GPIO1 | 内部上拉，低电平有效 |
| 另一侧 | GND | 按下时拉低 GPIO1 |

常见四脚按键同一侧的两个脚内部相连，应使用两侧各一个脚。固件以 20 ms 轮询，连续 3 次相同电平后确认状态；按住 500 ms 触发长按。

## 3. 引脚占用总表

| GPIO | 功能 |
| --- | --- |
| 1 | 按键 |
| 2 | microSD CS |
| 4 / 5 / 6 / 7 | ST7789 DC / RST / MOSI / SCLK |
| 8 / 9 / 14 | INMP441 SCK / WS / SD |
| 13 / 18 / 21 | microSD SCK / MOSI / MISO |
| 15 / 16 / 17 | MAX98357A BCLK / LRC / DIN |
| 19 / 20 | 保留原生 USB，不分配给外设 |

GPIO0 保留为 BOOT，不作为产品按键或外设引脚。

## 4. 供电与安全约束

当前开发阶段由电脑 USB-C 给 ESP32-S3 Nano 供电，功放使用 5 V，逻辑外设使用 3.3 V，并保持所有模块共地。

必须遵守：

1. MAX98357A 为 BTL 输出。扬声器两端只能接功放的 `+/-`，任何一端都不能接 GND。
2. INMP441 和当前 ST7789 仅按 3.3 V 使用；不要在未核对模块电路时改接 5 V。
3. 电脑 USB 供电期间，不要把另一组未经隔离的 5 V 同时接入开发板，避免电源倒灌。
4. 面包板和杜邦线适合功能验证，不是长期大电流和振动环境下的最终连接方案。
5. 喇叭与麦克风应物理隔离并固定，避免结构振动传入麦克风。
6. 最终结构应在功放电源附近布置储能/去耦，并以实测压降和噪声决定容量；当前仓库没有形成量产电源设计。

## 5. 棱镜与显示

- 分光棱镜不会让 TFT 变成透明屏；黑色像素仍有背光漏光。
- 当前 UI 使用深色外围和明亮中心区域，让矩形屏幕边缘在反射中更不明显。
- 显示方向由固件统一处理，不应同时在 UI 坐标、字体资源和面板驱动中重复镜像。
- 现有照片证明当前主页、天气页和语音状态在棱镜中方向正确；最终外壳仍需固定屏幕与棱镜相对角度。

## 6. 已验证与未完成

已完成实机功能验证：

- ST7789 显示、LVGL 页面和分光棱镜方向；
- 按键短按、长按和松开事件；
- INMP441 音量检测与可识别录音；
- MAX98357A 音调与 TTS 语音播放；
- microSD 挂载、读写和文本追加；
- Wi-Fi、天气、SNTP 与端到端语音链路。

未完成产品化工作：

- 独立电源树、去耦与浪涌测试；
- 定制 PCB、可靠连接器和线束；
- 喇叭后腔、麦克风声学隔离和外壳；
- EMC、温升、长期运行、跌落和安全认证；
- 背光 PWM 调光和整机功耗管理。
